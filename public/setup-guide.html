🛡️ POSH Training System - Complete Setup Guide

📋 System Overview

The POSH Training System consists of three integrated components:

1️⃣ Training Module

Interactive training platform for employees to complete the POSH awareness program with quizzes and acknowledgements.

File: POSH_Training_With_Intro_Page.html

2️⃣ Admin Dashboard

Tracks training completions, quiz performance, and overall program metrics for analytics.

File: POSH_Admin_Dashboard.html

3️⃣ Backend Dashboard

Secure admin-only access to view detailed employee responses and acknowledgement data.

File: POSH_Backend_Dashboard.html

📂 Required Files

Deploy all three files on your web server or hosting platform:

✓ POSH_Training_With_Intro_Page.html
✓ POSH_Admin_Dashboard.html
✓ POSH_Backend_Dashboard.html
💡 Tip: Place all files in the same directory for proper functionality. Each file operates independently but shares data via browser localStorage.

⚙️ How the System Works

Data Flow

Employee Completes Training ↓ Fills Acknowledgement Form ↓ Data Saved to Browser localStorage ↓ Admin Dashboard Reads & Displays Metrics ↓ Backend Dashboard Shows Detailed Responses

Data Saved for Each Employee

  • Personal Information: Name, Employee ID, Email, Department
  • Training Progress: Completion date, time, quiz scores
  • Acknowledgements: All 5 consent checkboxes status
  • Verification: Unique completion ID and verification code
  • Metrics: Number of quizzes completed

🚀 Setup Instructions

Step 1: Prepare the Files

  1. Download all three HTML files from outputs
  2. Keep all files in the same directory
  3. Do NOT rename the files

Step 2: Change Backend Credentials (CRITICAL)

  1. Open POSH_Backend_Dashboard.html in a text editor
  2. Find line 468-469 with these lines:
    const ADMIN_EMAIL = 'admin@azafashions.com';
    const ADMIN_PASSWORD = 'BackendAccess@2026';
  3. Replace with your secure credentials:
    const ADMIN_EMAIL = 'your.email@azafashions.com';
    const ADMIN_PASSWORD = 'YourSecurePassword123!';
  4. Save the file

Step 3: Optional - Change Admin Dashboard Password

  1. Open POSH_Admin_Dashboard.html in a text editor
  2. Find line 491 with:
    const ADMIN_PASSWORD = 'Aza@Admin2026';
  3. Change to your preferred password
  4. Save the file

Step 4: Deploy Files

  1. Upload all three HTML files to your web server
  2. Ensure files are accessible via HTTPS (not HTTP)
  3. Test each file by opening in browser

Step 5: Distribute Training Link

  1. Share the Training Module link with employees
  2. Set a completion deadline (e.g., 26th August 2026)
  3. Employees complete training at their own pace

Step 6: Monitor Progress

  1. Use Admin Dashboard for completion tracking
  2. Use Backend Dashboard for detailed employee responses
  3. Export data regularly for compliance records

⚠️ Important Considerations

🔒 Security: All data is stored in browser's localStorage. For production, consider implementing server-side storage for better security.
💾 Data Backup: Regularly export data from both dashboards to backup sensitive employee responses.
🔐 Password Management: Use strong, unique passwords for Backend Dashboard. Change credentials periodically.
📱 Mobile Support: All three systems are mobile-responsive and work on tablets and smartphones.
🌐 Browser Compatibility: Works on Chrome, Firefox, Safari, and Edge browsers.

🔧 Troubleshooting

Q: Employee data is not showing in dashboards?

A: Ensure employees have completed the full training and filled the acknowledgement form. Data is saved only after full completion on Slide 18.

Q: Backend Dashboard login not working?

A: Verify you are using the correct email and password. Check that you haven't accidentally used single/double quotes in credentials. Re-enter carefully.

Q: Data disappeared from dashboard?

A: LocalStorage data clears when browser cache is cleared. Export data regularly to prevent loss.

Q: Can I change quiz questions after training starts?

A: No. Editing quiz questions after deployment may affect employees' ability to proceed. Finalize questions before going live.

Q: How to give another admin access to Backend?

A: You must change the ADMIN_EMAIL and ADMIN_PASSWORD in the HTML file and give them the new credentials. Only one set of credentials is supported per file.

Q: Can employees retake the training?

A: Yes. Employees can return and complete again. Each completion creates a new entry with a new unique ID.
